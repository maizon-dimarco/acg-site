# American Change & Grow — website

Marketing site for American Change & Grow Management Consulting, LLC. Built by Maizon PMG.

Next.js (App Router) · TypeScript · Tailwind · deployed on Vercel.

- `src/app` — routes. The home page is `src/app/page.tsx`.
- `src/components` — shared components (`Lockup` is the logo as inline SVG; `HomeScript` is the home page's behaviour).
- `src/styles` — page stylesheets. Brand tokens live in `src/app/globals.css`.
- `public/brand` — logo files (SVG). `public/film` — the home film (scroll-scrubbed), idle loops, posters and stills.

```bash
npm install
npm run dev
```
